GENERATIVE AI Featured

Intelligent NL2SQL System

A multi-agent system that converts natural-language business questions into executable SQL queries for users with limited SQL knowledge.

Project overview

The system identifies relevant database tables, retrieves schema information and domain knowledge, generates SQL, executes the query, and presents the result through a Streamlit interface.

The project was developed for Customer Success analytics and evaluated using a dataset of 150 natural-language questions across easy, medium, and hard difficulty levels.

Main features

  • Natural-language to SQL generation
  • Multi-agent workflow using LangGraph
  • Table identification and schema retrieval
  • RAG-based domain knowledge retrieval
  • SQL execution using PostgreSQL
  • Query interpretation and refinement
  • Clarification handling for ambiguous questions
  • Execution-based and LLM-as-a-Judge evaluation
